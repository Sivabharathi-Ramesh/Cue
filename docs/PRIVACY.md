## What Cue accesses

| Permission | Why | When |
|---|---|---|
| Camera | To read text and recognise objects | While the app is open and looking |
| Microphone | To hear a voice command | Only while the user holds the talk key |
| Location | To answer “where am I?” | Only when the user asks |
| Vibration | To give touch feedback | During use |

## What stays on the phone

- Camera frames are processed on the phone for text recognition and object detection.
- Cue does not upload camera frames, audio, or recognised text to a server.
- Cue does not create an account and does not ask for a name, email, or phone number.
- Cue does not store photos, audio recordings, or transcripts.
- Cue does not show ads and does not sell data.

Reading and object recognition work without internet. Voice commands use the phone’s speech-recognition service and text-to-speech voice; those are provided by the phone and may use their own settings or data connection. Users can download offline language packs in Android settings.

## Pilot usage counts

For the pilot, Cue may offer an **opt-in** usage log to help the partner measure impact. It contains only counts, for example:

- number of sessions;
- number of readings and object descriptions;
- number of errors and refusals;
- selected language and mode;
- app version and device model.

It does **not** contain recognised text, images, audio, location history, or personal details. Participation is voluntary, and users can say no without losing access to the app. The log can be exported by the user or coordinator and deleted at any time.

## Permissions and control

- A user can refuse the camera, microphone, or location and still use the parts that do not need them.
- A user can turn off location at any time in Android settings.
- A user can uninstall Cue and remove its local data at any time.
- Cue explains a refused permission in plain language and tells the user how to change it.

## Children

Cue can be used by people under 18 with the consent of a parent or guardian. Pilot sessions involving minors follow the partner organisation’s safeguarding policy. Cue does not knowingly collect personal data from anyone.

## What Cue does not do

- It does not recognise faces or identify people.
- It does not record or store audio.
- It does not upload images or text.
- It does not provide navigation or replace a cane, guide dog, or mobility training.
- It does not give medical, legal, or financial advice.

## Changes

If this note changes, the new version will be included in the app and shared with the partner before the change takes effect.
